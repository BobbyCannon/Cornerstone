# Cornerstone

This repository is the **v3** line. It stays MIT. See [license.txt](license.txt).

The Presentation stack in this tree stops here. The rest of the framework is being rewritten as **vNext**. Reliability comes before speed, and speed comes before features. A change that hurts reliability does not ship. A feature that hurts speed does not ship.

When vNext launches, this repository is replaced. History and the current tree go away. Existing clones and forks will not fast-forward.

Changelog: [changelog.md](changelog.md). Docs: [Cornerstone.Documentation/Readme.md](Cornerstone.Documentation/Readme.md).

`Cornerstone.Presentation` includes source from the other projects. The upstream license and the other third-party notices are in [Cornerstone.Presentation/NOTICE.md](Cornerstone.Presentation/NOTICE.md).
