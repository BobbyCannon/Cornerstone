## When adding a quick start

1. One task per file under `QuickStart/`.
2. Link it from this table and from the parent [Readme.md](../Readme.md) Quick Start section.
3. Name the project, the entry test, and the session or builder that boots the platform.
4. Keep generator checklists and file maps in [Testing.md](../Testing.md).
